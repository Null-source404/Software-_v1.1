    REST API Reference

    JSON Endpoints · QR & Safety Guard

    POST /api/shorten

    Audits safety & reachability, blocks phishing/broken links (HTTP 422), and returns short link + QR code.

    curl -X POST http://localhost:3000/api/shorten \
  -H "Content-Type: application/json" \
  -d '{"originalUrl":"https://example.com","customCode":"my-link"}'

    POST /api/verify-url

    Pre-scans a URL for phishing indicators (brand spoofing, punycode, credential tricks) and broken status.

    curl -X POST http://localhost:3000/api/verify-url \
  -H "Content-Type: application/json" \
  -d '{"originalUrl":"https://paypal-secure-login.com"}'

    GET /api/stats/:shortCode & GET /:shortCode

    Fetches link telemetry + QR code or performs a verified HTTP 302 redirect.

    curl http://localhost:3000/api/stats/gh-repo
