    REST API Reference

    JSON Endpoints · Preview (+) · Quota & Safety Guard

    POST /api/shorten

    Creates a short link with optional customCode and maxClicks quota limit. Blocks phishing or broken URLs (HTTP 422).

    curl -X POST http://localhost:3000/api/shorten \
  -H "Content-Type: application/json" \
  -d '{"originalUrl":"https://example.com","customCode":"promo","maxClicks":10}'

    GET /:shortCode+ & GET /preview/:shortCode

    Opens the Safe Destination Preview interstitial page showing target URL, safety status, QR code, and remaining click quota before redirecting.

    curl "http://localhost:3000/gh-repo+?format=json"

    GET /api/stats/:shortCode

    Returns click counts, quota status, QR code, and breakdown by device, browser, referrer, and daily timeline.

    curl http://localhost:3000/api/stats/gh-repo
